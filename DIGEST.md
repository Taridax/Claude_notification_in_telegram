# Ежедневный дайджест: строительство и проектирование

Инструкция для запуска по расписанию (Routine, будни 9:12 по Ташкенту).
Результат: одно сообщение в группу Telegram `-1003022426387` или ничего.

## Шаги

1. Отключи hook-уведомления этого запуска: `touch .no-telegram-hooks`
   (в чат должен уйти только дайджест).
2. Получи новые записи: `python3 scripts/fetch_feeds.py > /tmp/feed.json`.
   Если в `errors` есть ошибки, учти их в шаге 7.
3. Отбери записи, которые касаются **изменений в законодательстве в сфере строительства
   и проектирования**:
   - градостроительство, архитектура, территориальное планирование, генпланы;
   - проектирование, инженерные изыскания, экспертиза проектов (градостроительная,
     государственная), проектно-сметная документация, ценообразование и сметы в строительстве;
   - строительные нормы и правила (ШНК, КМК, ГОСТ/стандарты для строительства),
     технические регламенты на здания, сооружения, строительные материалы;
   - разрешения на строительство, ввод объектов в эксплуатацию, госархстройнадзор,
     технический и авторский надзор, приёмка объектов;
   - лицензирование и требования к строительным и проектным организациям, их рейтинг,
     квалификация специалистов (ГИП и др.);
   - закупки и подряд в строительстве, долевое и жилищное строительство,
     реконструкция, снос, сейсмостойкость, энергоэффективность зданий;
   - решения Минстроя (Министерства строительства и жилищно-коммунального хозяйства)
     и Инспекции по контролю в сфере строительства.

   Не включай записи, где строительство упомянуто вскользь (например, строительство
   конкретного объекта в рамках программы без изменения правил), а также обзоры
   и мероприятия без изменения норм. Если по заголовку и описанию не понятно,
   открой страницу документа (`curl -sL -A Mozilla/5.0 <link>`) и реши по тексту.
4. Если подходящих записей нет, ничего не отправляй и переходи к шагу 6.
5. Составь дайджест (обычный текст без Markdown, Telegram сам сделает ссылки кликабельными):

   ```
   🏗 Дайджест законодательства: строительство и проектирование
   <дата, например 12.10.2026>

   1. <Название документа или новости>
   <Вид и номер акта, дата принятия и вступления в силу, если известны>
   <1–2 предложения: что меняется для строителей и проектировщиков>
   <ссылка>

   2. ...

   Источники: lex.uz, norma.uz
   ```

   Если lex.uz и norma.uz пишут об одном документе, объедини их в один пункт
   с обеими ссылками. Отправь:
   `python3 scripts/notify_telegram.py --chat -1003022426387 < /tmp/digest.txt`
   и проверь, что код выхода 0.
6. Отметь записи как обработанные и сохрани состояние в основной ветке репозитория
   (следующий запуск начнётся с неё):
   ```
   BASE=$(git ls-remote --symref origin HEAD | sed -n 's#^ref: refs/heads/\(.*\)\tHEAD$#\1#p')
   git fetch origin "$BASE" && git checkout -B digest-state "origin/$BASE"
   python3 scripts/fetch_feeds.py --commit > /dev/null
   git add state/seen.json && git commit -m "Update digest state $(date +%F)" && git push origin "HEAD:$BASE"
   ```
   Если коммитить нечего, это нормально. Если дайджест не удалось отправить,
   не выполняй этот шаг: записи попадут в дайджест завтра.
7. Если обе ленты недоступны, отправь в личный чат короткое сообщение об ошибке:
   `python3 scripts/notify_telegram.py --chat 8423645052 "⚠️ Дайджест: ленты недоступны: <ошибки>"`.
